TTL Digital Logic / Hardware Game

數位電路期末專題｜拔河遊戲製作

以 TTL 數位邏輯電路設計雙人即時拔河遊戲。兩隊透過按鍵競速控制 LED 位置，率先將指示燈推至對方終點者獲勝並自動加分；若 15 秒內未分出勝負，系統會自動停止玩家輸入並進入隨機決勝。

Core Technologies

核心技術

Up / Down Counter

利用 74LS190 控制拔河位置，根據兩隊按鍵輸入改變計數方向。

Flip-Flop / State Control

保存遊戲狀態，控制開始、暫停、勝負與下一局。

LED Position Display

將 Counter 狀態轉換為 LED 位置，直觀呈現目前拔河結果。

15-second Timer

利用 Clock 與 Counter 建立遊戲時間限制。

Automatic Scoring

達到終點或完成隨機決勝後，自動更新勝方分數。

Pseudo-random Decision

15 秒內未分出勝負時，透過數位邏輯進行隨機勝負判定。

Design Adaptation

電路改編設計

參考既有數位拔河電路的計數與 LED 顯示架構，保留 Up/Down Counter 控制位置的核心設計，並依遊戲需求重新規劃控制邏輯，加入 15 秒限時、自動暫停、自動計分與隨機決勝機制，完成具完整遊戲流程的改良版本。

改編過程中需重新整合 Counter、Flip-Flop、Decoder 與 Logic Gates 之間的訊號控制，使新增功能能與原有電路協同運作。

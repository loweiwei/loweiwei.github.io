Main System Pipeline

從定位、感知到下一步行動

01

Localization

載入地圖，透過 AMCL 持續估計 Robot Pose，並記錄 Home Pose。

02

TaskController

依狀態判斷搜尋、導航、過橋、抓取或開門階段，並設定 YOLO 辨識目標。

03

RGB-D + YOLO

執行 Detection / Segmentation，取得 Target Position、Distance、Bridge Entry、Knob Offset。

04

TaskController Decision

整合 State、Robot Pose、Map、YOLO 與 Depth，決定下一步行動。

Decision Pipeline

TaskController 如何決策

01

Explore / Search

尚未找到目標時，以 Frontier / Rotate Search 搭配 YOLO 搜尋；找到後更新 Target 並重新決策。

02

Map Planning

目標距離較遠時使用 Hybrid A*；失敗時 fallback 至 Grid A*，再沿 Waypoints 前往目標附近。

03

Close-range Action

接近目標後改用 YOLO delta_x 與 Depth 進行 Visual Servo，完成置中、接近、抓取或操作。

Task Execution Grab / Return / Cross / Press / Push State Transition Next State

Technical Highlights

技術亮點

RGB-D 3D Target Localization

將 YOLO 2D 偵測與 Depth、Camera Geometry、TF 結合，取得可供導航與操作使用的三維目標位置。

Global Navigation + Local Visual Servoing

遠距離使用地圖規劃，近距離改用 YOLO offset 與 depth 精細對準。

Hybrid A* + Grid A* Fallback

Hybrid A* 同時考量位置、朝向與車體 footprint，失敗時切換 Grid A*。

Non-blocking Task State Machine

將搜尋、導航、抓取、過橋與開門拆成不同狀態，持續處理感測資料、Timeout 與失敗重試。

Project Motivation

專題動機與目標

在區塊鏈課程中學習 DeFi 的借貸與流動性機制後，希望進一步實作一套可執行的 Smart Contract 系統，理解抵押、借貸、利息、清算、流動性提供與治理之間如何互相影響。

MiniBank System Overview

DeFi System Flow / Architecture

LP

Liquidity Provider

Supply mDAI → 提供流動性 → 取得 aMDAI Share → 獲得 BKT Reward

Borrower

Collateral Borrowing

Deposit ETH → 根據 LTV 借出 mDAI → Repay Principal + Interest

BankV3

Liquidity Pool Collateral / Debt / Interest / Reward / Liquidation
Liquidator

Risky Debt Handler

Health Factor < 1 時 Repay Risky Debt，取得 ETH Collateral + Liquidation Bonus。

Price Oracle

ETH/USD Price

計算 Collateral Value、Borrow Limit、Health Factor 與 Liquidation Condition。

DAO / BKT Holder

Governance

Delegate → Propose → Vote → Timelock → 更新協議參數。

Core Assets

系統主要資產

ETH

Collateral

Borrower 使用 ETH 作為抵押品，決定可借額度與清算風險。

mDAI

Liquidity / Borrowing Asset

LP 提供 mDAI 流動性，Borrower 借入 mDAI，Liquidator 也使用 mDAI 代償債務。

aMDAI

LP Share Token

LP Supply mDAI 後取得，代表其在 Liquidity Pool 中的持有份額。

BKT

Reward / Governance Token

作為 LP / Borrower 獎勵，並提供 DAO Voting Power。

Main Participants

主要參與角色

LP

提供 mDAI 流動性，取得 aMDAI Share 與 BKT Reward。

Borrower

抵押 ETH 借入 mDAI，並維持安全的 Health Factor。

Liquidator

當 Borrower 抵押不足時代償部分債務，並取得抵押品與 Liquidation Bonus。

DAO / BKT Holder

使用 BKT 參與 Proposal 與 Voting，調整協議參數。

BankV3

管理 Liquidity Pool、Collateral、Debt、Interest、Reward、Liquidation 與 Governance。

Oracle

提供 ETH/USD Price。

Key Concepts

LTV / Health Factor

LTV

Loan-to-Value

決定抵押品最多能借出多少資產。

Borrow Limit = Collateral Value × LTV
ETH CollateralBorrow LimitBorrow mDAI

Health Factor

清算風險指標

衡量目前抵押品是否足以支撐債務。

HF ≥ 1 → Safe
HF < 1 → Liquidatable

Lending Flow

借貸流程

LP Supply mDAI Liquidity Pool Borrower Deposit ETH Borrow mDAI Repay + Interest LP 收益 / Protocol Reserve
Health Factor < 1 Liquidator Repay Debt Receive ETH Collateral + Bonus

Incentive & Revenue Distribution

參與誘因與收益分配

LP

提供流動性，取得 aMDAI Share、部分借款利息與 BKT Reward。

Borrower

保留 ETH Exposure，同時取得可使用的 mDAI 流動性。

Liquidator

協助處理高風險債務，取得 Collateral 與 Liquidation Bonus。

Protocol / DAO

從利息與清算機制中累積 Protocol Reserve，並透過 BKT Governance 管理協議參數。

LP 提供的不是單純「存款」，而是可供 Borrower 使用的流動性；作為交換，LP 取得資金池份額並分享協議收益。

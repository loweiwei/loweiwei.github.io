System Architecture

從主程式到場景模組的分層架構

專案不是單一 shader demo，而是把圖學課程中的場景管理、模型載入、互動控制、碰撞與後處理整合成可操作的 3D 極地場景。

main.cpp

建立 window / OpenGL context，載入 shader、texture，建立 Player、Camera、WorldManager，並進入 main loop。

WorldManager

建立 tile-based 場景，管理 Terrain、Water、IceMountain、Flag、OBJ objects 與 render 順序。

Player + Camera

處理 WASD、跳躍、重力、第三人稱相機、地形高度修正與玩家 OBB。

Module Design

各模組理念與責任

01

Terrain System

以 Perlin noise 產生雪地高度，再用 flat / slope / crevasse / ridge masks 控制地形語意，而不是只依賴隨機 noise。

02

Water System

由 WaterManager 建立湖泊、河流、裂縫水面與大範圍水域，讓極地場景有不同尺度的水面表現。

03

Scene Assets

透過 tinyobjloader 與 stb_image 載入 tent、campfire、tree、pier、ladder 等 OBJ / texture，並為物件建立 OBB。

04

Player & Collision

移動時建立 future OBB，使用 OBB vs OBB SAT 分軸檢測，分別處理水平碰撞、平台落地與天花板碰撞。

05

RobotModel

以 cube 與 parent-child transform 組出階層式機器人，支援 walk、run、bow 與手動關節旋轉。

06

Post-process

先將場景畫入 framebuffer，再讀取 color / depth texture 重建世界座標，套用邊界霧、高度霧與極光。

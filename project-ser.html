Speech Emotion Recognition / MFCC / 1D CNN

語音情緒辨識｜MFCC × 1D CNN

訊號與系統期末專題

本專題以論文 Speech Emotion Recognition Based on 1D CNN and MFCC 為基礎，重現「語音訊號 → MFCC 特徵 → 1D CNN 情緒分類」流程，並進一步檢查原始高準確率是否受到資料切分與 augmentation leakage 影響。除了重現 baseline，我也設計 MFCC ablation、leakage-free evaluation、cross-dataset experiment 與簡易網頁 demo，分析模型真正的泛化限制。

Project Story

專題定位：從論文重現開始，但重點是檢查模型是否真的泛化

語音情緒辨識的輸入不是乾淨的表格資料，而是一段會受到說話者、語速、錄音設備、背景環境與語料收集方式影響的連續訊號。模型在同一資料集內得到高 accuracy，可能代表它學到情緒相關聲學特徵，也可能代表它記住了資料集特定的錄音模式、speaker 特徵或 augmentation 後的相似樣本。

因此，我把這個專題分成兩層：第一層是重現論文方法，建立 MFCC + 1D CNN 的完整訓練流程；第二層是重新檢查評估設計，包含 leakage-free split、不同 MFCC 參數的 ablation，以及跨資料集測試。最後的重點不是單純追求最高分，而是說清楚分數在什麼條件下成立。

我實作的是什麼

從 CREMA-D / RAVDESS 音檔讀取、固定長度、資料增強、MFCC 特徵、label encoding、1D CNN 訓練，到 classification report、confusion matrix、learning curves 與 web demo。

我想回答的問題

MFCC + 1D CNN 是否能重現論文表現？不同 MFCC 參數是否影響結果？如果避免 augmentation leakage 或換資料集測試，accuracy 會發生什麼變化？

這頁怎麼讀

先看 pipeline 理解資料如何變成模型輸入，再看 baseline 結果；接著看 leakage-free 與 cross-dataset，理解為什麼高分不一定代表強泛化能力。

Data & Feature Pipeline

從音訊到模型輸入：先把語音轉成固定長度 MFCC 序列

原始語音長度不一致，不能直接丟進固定輸入形狀的 1D CNN。前處理先將音訊載入為 22,050 Hz、裁切或補零到 2.5 秒，再做 noise addition 與 pitch shifting。接著可選擇 pre-emphasis、MFCC 維度、FFT size、hop length、delta feature 與 utterance-level normalization，最後把每段音訊轉成 (time, feature_dim) 的序列。

Dataset

CREMA-D

使用 6 類情緒：sad、angry、disgust、fearful、happy、neutral。檔名中包含 speaker 與 emotion code，可用於 label mapping 與 leakage-free grouping。

Dataset

RAVDESS

原始支援 8 類情緒：neutral、calm、happy、sad、angry、fearful、disgust、surprised；跨資料集時轉為共同 6 類 label space。

Feature

MFCC

MFCC 將語音轉成接近人耳感知尺度的頻譜特徵。模型不是直接看 waveform，而是學習 MFCC 時序變化與情緒類別之間的關係。

Augmentation

Noise + Pitch Shift

使用高斯雜訊與 pitch shifting 增加資料變化；但 augmentation 必須只作用在 training set，否則可能造成 train/test leakage。

1D CNN Model

模型架構：沿著 MFCC 的時間軸學習局部聲學模式

1D CNN 適合處理序列型特徵。這裡每個時間步都有一組 MFCC feature，卷積層沿時間方向掃描，學習短時間內的聲學變化；Batch Normalization 穩定訓練，MaxPooling 逐步壓縮時間長度，最後 Flatten 接 Dense layer 與 Softmax 輸出情緒分類。

01

Conv Block 1-2

兩層 512 filters、kernel size 5 的 Conv1D，搭配 BatchNorm 與 MaxPooling，先抽取較低階的時間局部特徵。

02

Conv Block 3-4

兩層 256 filters，繼續整合較長時間範圍的聲學變化，降低序列長度並保留情緒相關 pattern。

03

Conv Block 5

128 filters、kernel size 3，進一步壓縮特徵並輸出給分類器。

04

Classifier

Flatten 後接 Dense 512、BatchNorm 與 Softmax，輸出每個 emotion class 的機率。

Evaluation Protocol

關鍵問題：資料增強如果發生在切分之前，測試集可能不再獨立

原論文做法是先對完整資料做 noise addition 與 pitch shifting，再把擴增後資料切成 train/test。這樣可能讓同一個原始 utterance 的不同增強版本同時出現在 train 與 test；模型看似是在辨識 unseen speech，其實可能見過非常相似的聲音版本。因此我重新設計成「先切分原始 utterances，再只對 training set augmentation」。

Original Setup

先 augmentation，再 train/test split

這個流程容易高估模型能力，因為測試資料可能和訓練資料共享同一原始語音來源，只是 noise 或 pitch 不同。

Interpretation

這個結果代表什麼？

01

Original Accuracy may be optimistic

原本高 accuracy 可能部分受到資料切分與 augmentation leakage 影響。

02

Train–Validation Gap increases

重新切分後，模型在 unseen speech 上的表現明顯下降，顯示泛化能力比原始 evaluation 弱。

03

Protocol matters

SER 的結果不只受模型架構影響，資料切分與 augmentation policy 也會直接改變最終分數。

High Accuracy ≠ Strong Generalization

當資料切分改為 leakage-free 後，模型表現明顯下降，表示原本高分不一定代表對真正 unseen speech 具有同等泛化能力。

Acoustic Feature & MFCC Ablation

MFCC 不是固定答案：特徵設定會隨資料集改變最佳結果

我針對 MFCC dimension、hop length、FFT size、pre-emphasis 與 delta feature 做 ablation。結果顯示「更多特徵」或「更高解析度」不一定更好，因為不同資料集的錄音條件、說話風格與類別分布會改變模型需要的時間與頻率資訊。

01

沒有一組參數對所有 Dataset 都最佳

CREMA-D 與 RAVDESS 對 MFCC Dimension、Hop Length、FFT Size 的最佳設定不同，顯示聲學前處理需要依 dataset 特性調整。

02

更多特徵不一定更好

增加 MFCC 維度、FFT Size 或 Delta Feature 不一定提升表現，有時甚至會加入冗餘資訊。

03

時間與頻率解析度需要平衡

Hop Length 與 FFT Size 都存在 dataset-dependent trade-off，不能單純追求更細時間解析度或更高頻率解析度。

Cross-Dataset Generalization

跨資料集測試：同一模型換到不同語音資料域後大幅下降

為了檢查模型是否學到一般化的情緒聲學特徵，我把 label space 對齊為共同 6 類，並做 RAVDESS → CREMA-D 的 cross-dataset evaluation。結果顯示模型在單一資料集內可得到高分，但直接跨資料集測試時 accuracy 降至 35%，代表 dataset domain 本身是 SER 的重要限制。

Why Does the Domain Gap Happen?

為什麼會有 Domain Gap？

01

Recording Condition

不同 dataset 的錄音設備、背景環境與音訊品質不同，造成輸入訊號分布差異。

02

Emotion Expression

不同說話者與資料收集方式，對相同 emotion 的聲學表現可能不一致。

03

Feature Dependency

前面的 MFCC ablation 顯示，不同 dataset 對 MFCC dimension、hop length、FFT size 等設定的敏感度不同。

04

Class Distribution

不同 emotion 的樣本數與類別分布不同，也可能造成模型 prediction bias。

High In-Dataset Accuracy ≠ Strong Cross-Dataset Generalization

模型在單一資料集內的高 accuracy，無法直接代表對 unseen speech domain 具有相同泛化能力。

Web Demo & Limits

除了離線訓練，也整理成可上傳音檔的簡易 Demo

Repository 內另外包含一個 FastAPI demo：使用者可上傳 WAV，後端執行 SER emotion prediction，也串接 Whisper 做語音轉文字，再用 FLAN-T5 產生一句摘要。這個 demo 主要展示 inference pipeline 如何包成應用，不把它當作正式研究評測。

可以支持的 claim

專題完成 MFCC + 1D CNN 的論文重現、ablation、leakage-free evaluation、cross-dataset analysis 與 demo pipeline。

不能過度宣稱

SER 預測的是語音聲學上的 emotion pattern，不等同於驗證使用者真實心理狀態。

主要限制

跨資料集結果顯示 domain gap 很大；CPU 上執行 Whisper / LLM demo 也可能較慢。

Key Findings

關鍵發現

Reproduction ≠ Generalization

重現接近論文的 accuracy，不代表模型真的能泛化到 unseen speech。

Evaluation Protocol Matters

資料切分方式與 augmentation policy 可能大幅影響最終結果。

Dataset Domain Matters

模型表現不只受到模型架構影響，也受到語料來源、錄音環境與 label design 影響。
